由青州一件背屏三尊造像引出的观察札记

2026-10-22

——断臂、卯孔与石匠的容错

本文是一次对实物痕迹的推敲记录，不是论文。观察对象是青州博物馆那件贴金彩绘背屏式一佛二菩萨三尊像（北魏晚期至东魏，石灰石，高122cm）。写作时不强行给结论盖章，能确认的确认，能推的推，推不动就明说。

一、缘起：图录解说给了一个可疑的说法

展厅里常能听到一句现成的解说：这尊佛的两处断臂处留有圆孔，原先是"预留插榫、配可拆卸手臂"的。这句话听着顺，但经不起推敲。

真正的线索不在解说里，在实物上——同一件造像的另外一侧，还完整保留着一只手臂。这只手是判断全局的钥匙。

二、同器对照：完好手臂是原生的"内部参照物"

【可观察实物事实】 佛像一侧（观者视角的左手）的浮雕手臂完整。观察其： - 石材、衣纹、雕刻刀痕连续过渡，袈裟褶襞从躯干顺流而下、包住上臂小臂直至手背，减地层次连贯，找不到拼缝； - 手臂根部与躯干相连的"石梁"，和袈裟帔帛浮雕融成一体，是一次起坯减地雕出来的支撑结构； - 手掌、指节、衣纹上的彩绘层连续覆盖，未见拼合缝隙处的分界。

【推理，证据较强】 这件造像的原生方案，就是同石一体高浮雕悬臂，靠衣纹飘带做结构补强。它本身否定了"这尊佛像最初就是双臂分体插榫设计"的通俗说法——对称的另一侧并没有这个设计，同一件造像不可能一半一体、一半预设分体。

小结：以完好手臂作内部参照，这件造像双臂在原生阶段是一体浮雕，不存在原生预留装配卯。

三、卯孔的时序链：先修复，再被砸碎

带圆孔的一侧（观者视角的右手）是残断茬口。把它放回这条因果链里看：

  1. 原生状态：一体浮雕手臂（由完好侧推断）
  2. 初次断裂：悬臂崩断，留下参差碴口
  3. 古代修复工序——这一步是推演的核心： 只要是有意识的榫卯修复，工匠必然先把破碎碴口修整成平整基面，再凿卯、配补臂、灌铅锡合金固定、重妆彩绘贴金。
  4. 修复后继续供奉一段时期
  5. 二次破坏（入窖前）：暴力砸击下，卯口这个应力薄弱点再次崩开，原本修平的基面、孔缘被再次打碎
  6. 埋藏入窖

【关键推理】今天肉眼所见卯口边缘的残破，不是"修复时没修平"，而是"修好之后又被砸崩"。 不能用"卯口是残破的"，反推它从一开始就不是修复卯。

四、区分两类工艺：背屏浮雕 vs 单体圆雕 vs 金铜造像

很多误区的根源，是把不同器物的工艺互相套用。

器物类型 原生手臂范式 说明
北魏晚—东魏背屏式高浮雕三尊（本件所在门类） 同石一体浮雕，衣纹做石肋补强 原生不预设分体插臂；是主流范式
北齐单体圆雕石佛 少量原生预制分体榫卯手臂 有可靠标本，但数量少
北朝金铜造像 原生分铸拼插（主尊/背光/底座） 是铸造体系的成熟做法

关键区分： - 原生分体预制：开料之初就设计成可装配构件； - 断裂后的补救修复：雕好使用后断了，凿卯接回。 科普文字常常把后者直接说成前者，这是概念偷换。

五、文献可证的部分

【文献可证】 1. 李清泉《试析青州龙兴寺造像贴金彩绘并非均系北朝装饰》，《石窟与土遗址保护研究》2008年第2期 - 核心论点：龙兴寺很多残臂断口上的卯眼，是断裂之后古人修复时二次开凿的修复卯，不是原生装配孔； - 修复手段两种：铁锔加固、榫卯灌铅锡合金；检测到铅锡残留为物证； - 统计：150余件拼对造像中约40余件带古代修复痕迹。 2. 夏名采《青州龙兴寺佛教造像窖藏》（山东美术出版社，2004）：发掘领队原始底档，背屏三尊描述为同石一体高浮雕，只记"手部残"，未将手臂归为预制分体构件。 3. 何利群《华北东部北齐至隋代菩萨造型特征》（2022）：邺城北吴庄白石造像同样存在"磨断面+凿卯+铁铆接臂"，且观察到：这种古代榫卯修补集中在北魏晚期—东魏—北齐，隋唐石造像上几乎找不到同类古修复痕，可作分期标尺。 4. 郑岩关于龙兴寺破碎、修复、瘗埋的讲座与随笔：从信仰层面解读"补像续法身"，但强调不做痕迹微观考古。

【无法确认的边界】 - 目前没有一件窖藏出土标本，是出土时补配手臂仍牢牢接在卯上、完整保留到今天。现有证据全是结构痕迹、金属填充物、彩绘叠压，不是"完整接好的成品"。展厅里那些拼完整的，多是现代考古粘接复原。 - 没有任何学者做过量化普查：龙兴寺全部修复卯里，出土时保留平整基面的占比多少、完全崩碎的多少。现有判断基于个案图版和整理者文字，留有讨论空间。

六、两个开放假说：工坊即时补救 vs 供奉期修复

这是最迷人、也最难证实的一环。

  • 假说A【雕刻当场补救】：工匠减地雕刻悬臂时石材崩断，当场修断面、凿卯、补臂。逻辑上完全成立——民间石坊石材品质参差、悬出浮雕风险高，容错机制理应存在。
  • 假说B【供奉破损后修复】：造像完成、供奉一段时间后断裂，信徒修断面凿卯补臂（法难后"续法身"）。

难点：两种操作留下的錾磨痕、卯孔形态几乎完全相同，痕迹是同质的。唯一鉴别钥匙是彩绘层的叠压顺序： - 若原生底层彩绘连续覆盖在修磨面上 → 属于雕刻阶段当场修好、再统一上第一遍彩； - 若修平面上无底层彩、修复后才上新的彩绘层 → 属供奉期修复。

而青州这批造像风化、彩绘残碎，这个层序很难稳定提取。所以假说A长期停留在逻辑推演，无法用现有证据定论，只能标为合理推测、留作开放问题。

七、待观察清单 / 研究缺口

  1. 系统普查龙兴寺修复卯标本，统计出土时保留平整修复基面的比例——目前缺失；
  2. 有没有背屏浮雕标本，凭借彩绘层序能区分"工坊即时修补"与"供奉期修复"——目前缺失；
  3. 为什么这套铅锡榫卯断臂修复工艺集中在东魏北齐、隋唐石造像反而少见——只有个案观察，无系统解释；
  4. 通俗图录"原生分体插臂"的说法如何流传开来、如何纠偏——建议在文档里持续追踪。

八、增补：隋唐原生分体卯榫接臂，与北朝修复卯的对比

前置共识： 北朝（青齐、邺城窖藏所见）的卯孔，绝大多数是破损之后二次开凿的修复卯；而隋唐出现的手臂卯榫，很多是原生设计阶段就规划好的分体装配结构——这是二者最根本的分野，也是风格、断面、接口形态全部差异的源头。

8.1 隋唐这类原生分体手臂造像的形制与风格背景

适用品类： 1. 大型单体圆雕立佛、菩萨（不再是北朝占主流的背屏高浮雕；背屏式在隋代快速衰落，初唐后基本退出主流）； 2. 大型石窟外的供奉单体石像、寺院大型造像； 3. 彩绘泥塑、夹纻造像（木骨+泥塑，分体组装在隋唐非常普及，反过来影响石雕制作思路）。

背景变化：北朝东部工坊这套"卯孔+铅锡灌固"，起源是破损补救工艺；到隋唐，工匠把这套装配思路主动吸收，转化为原生生产工艺。隋唐造像体量更大、菩萨肢体舒展、手臂大幅度外扬、持物繁多（杨柳枝、净瓶、宝珠、香炉、长柄法器），悬臂更长、悬空风险极高。原生分体，是为了解决雕刻时石材断裂风险，属于前置工艺预案，而不是坏了之后的补丁。

原生图像风格特征： - 肢体更舒展柔软，偏写实化的肉身感，不再依靠帔帛衣褶石梁做结构加固； - 菩萨手臂常向外、向前大幅度探出，脱离躯干很远，飘带更多是装饰，不再承担核心承重； - 手臂末端常持大件、长型法器，一体浮雕时极易折断； - 衣纹是薄贴体、圆转流畅的隋唐样式，和北朝褒衣博带、阶梯状厚重褶子完全不同。

8.2 接口、断面、卯榫形态的关键对比

观察维度 北朝（青州/邺城窖藏）修复卯 隋唐原生分体预制卯榫手臂
卯孔开凿时机 造像成型后断裂，才二次凿孔；补救修复 坯料设计阶段就规划，起坯时预留接口；原生工艺
断面基面性质 基面=旧断裂碴人工二次修磨整平，范围局限在断裂区域；与原生雕刻刀痕是两套不连续工序 基面=刻意设计的装配接合面，雕刻躯体时一次打磨规整，边界规整、轮廓预设；原生刀痕在接合面边缘连续收束
卯孔形态 圆孔居多、孔径不大、孔壁简易、无定位槽；填充物多为铅锡合金、少量石灰浆 圆孔、方卯、子母榫都有；大型隋唐造像会做双卯、定位销防扭转；固定材料以铁销、石灰糯米类灰浆为主，铅锡灌注显著变少
断面轮廓形状 轮廓随机，由当初断裂位置决定，无造型逻辑；多在手臂根部应力最弱处，位置随机 接合断面轮廓规整、有设计感，大多在上臂近肩肘处，分割线统一对称，左右手臂接口位置高度一致
与衣纹浮雕关系 衣纹帔帛原是一体连续浮雕，断裂打断衣纹；修复卯强行介入，破坏衣纹连续性 衣纹帔帛在分割位置主动收束、断开；设计上接受"手臂是独立构件"，飘带分雕在躯体块、手臂块上，拼合后衔接
二次破坏后样貌 再次折断时破碎点优先在修复卯薄弱位置，修平基面易崩碎——即卯口四周残破 断裂可发生在榫卯接口/手臂小臂手腕/躯体三处；接口是设计受力节点但应力分配更均衡；残件断口常沿预设装配面整齐分开，不一定崩碎卯口基面
彩绘妆銮层序 底层是原生北朝妆彩；修磨面之上覆盖修复后的二次重妆层，两层彩有时序差 躯体、手臂分开雕刻、分别打磨，组装合拢后统一整体上底色、统一彩绘；彩绘层跨接缝连续，无"先有造像、后补妆"分层

8.3 极易混淆的一处边界

隋唐同样存在破损之后、后世补修的修复卯，不是隋唐所有卯孔都是原生分体！ 区分口诀：

隋唐卯孔分两类： A类：预制装配卯——接合面规整、分割位置对称、接缝处衣纹主动收束、彩绘跨缝连续；原生分体设计。 B类：隋唐时期的修复卯——和北朝修复卯逻辑完全一致：随机断口、打磨旧碴、凿孔补臂；只是造像本身风格是隋唐样式。

不是"只要是隋唐佛像带卯，就一定是原生分体"。风格时代只是背景，最终判据仍是断面、基面、彩绘叠压这套痕迹标尺。

8.4 与青州东魏背屏三尊的对照小结

  1. 这件北朝造像的卯，是在一体浮雕范式里的意外补救；隋唐原生分体，是工匠主动放弃一体悬臂方案，把分体装配变成常规生产手段——这是底层观念的转变。
  2. 北朝背屏造像，工匠优先用衣纹石肋保住一体浮雕；隋唐大型圆雕菩萨，工匠直接接受分体，作为前置方案。
  3. 痕迹上最核心的一眼识别点：
  4. 断面位置随机、衣纹被硬生生切断、基面是破碎碴口改修而来 → 偏向【修复卯】（北朝大量，隋唐也有）；
  5. 左右上臂分割位置对称统一、接缝轮廓整齐、衣纹在接缝处刻意收束呼应、合拢后图像流畅 → 偏向【原生预制分体卯】（隋唐典型）。

8.5 可加入的开放问题

  1. 隋代作为过渡期：背屏造像衰亡、单体圆雕兴起，从"修复卯"到"原生分体卯"的工艺转化，最早的标本节点在哪里？
  2. 北朝铅锡灌卯的修复传统，如何过渡到隋唐铁销+灰浆装配体系？材料变化的动因是什么？
  3. 地域差异：长安、洛阳隋唐造像分体卯的习惯，与山东、河北东部遗存有无区别？

九、增补：唐代摩崖（龙门卢舍那）——连崖一体开凿，不参与榫卯体系

奉先寺卢舍那大佛造像群，和青州、邺城窖藏那种可移动独立石块造像，是完全不同的制作基底。

9.1 卢舍那是连崖原生岩石开凿，不是独立料石

卢舍那是直接从山体崖壁原生岩石上向内减地开凿的摩崖龛像，不是先采石、单独下料做成独立石块圆雕。所以它天然不存在"预制分体榫卯装配手臂"这个选项——手臂、躯干、后背崖壁是同一块山体岩体，原生一体连续，没有预设装配接口。

9.2 它断臂的性质：岩体悬挑崩落，不是榫卯结构失效

  • 双臂消失，是外挑的悬臂岩体本身属悬挑结构，石灰岩渗水、冻融、层理裂隙发育，沿岩石层理整块崩落；
  • 断口是顺着山体岩层自然裂隙拉开的，不存在任何原生预留卯孔、装配面，也未发现北朝式那种二次修复的打磨基面+修复卯痕迹。

9.3 帮我们划清唐代两条石刻路线

  • A路线：摩崖龛像（龙门奉先寺这类）——山体原生岩石开凿，全身所有肢体一体连崖，不可能原生分体榫接；手臂崩了是崖体残损，几乎没有用榫卯补石臂的修复案例（工程量、山体条件都不支持）。
  • B路线：独立可移动的单体圆雕石像（洛阳、长安寺院供奉的散石造像）——石材是单独开采的料石；盛唐、初唐一部分大型菩萨立像，才会出现原生规划分体卯榫手臂的做法，属于预制装配方案。

很多人笼统说"唐代造像就流行分体榫接手臂"，奉先寺是最好的反例：唐代不是所有石像都分体，分体卯榫主要局限于独立下料的单体圆雕，摩崖造像几乎不用这套办法。

9.4 三条石刻路线的结构对照

路线 制作基底 手臂范式 断臂后果
北朝背屏浮雕（青州） 独立石块、一体浮雕悬臂 原生一体；断裂后人工修复卯（补救） 修平基面+凿卯+补臂
唐代单体圆雕（部分寺院造像） 独立石块 设计阶段拆分躯体+手臂，预制卯榫（原生装配预案） 断口常沿预设装配面整齐分开
唐代摩崖（卢舍那） 连崖岩体一体开凿 原生连崖一体，无分体装配逻辑 悬挑崩落是岩体灾害，极少石质补臂修复

9.5 一个延伸观察猜想（开放问题）

皇家主导的大型摩崖工程，和民间工坊独立造像，工匠应对悬臂断裂风险的思路完全不同： - 摩崖这边，靠控制外挑幅度、调整衣纹岩体厚度、甚至用背光/身光岩体做支撑；实在撑不住，就接受风化崩损，而不会设计分体拼装； - 民间独立石料造像，石料成本高、整块大料雕刻容错低，才发展出要么雕刻现场修补、要么直接预先分体的方案。

小结：卢舍那大像龛作为盛唐皇家摩崖，属崖壁原生连续岩体开凿，手臂与山体一体，不存在原生分体卯榫设计；它手臂残失是悬挑岩体顺层理风化崩落，和独立单体造像的榫卯装配、断臂补修属两套完全不同的工艺体系，不能混同比较。

十、可复用的痕迹观察标尺（以后看任何残像都用这套）

按分层顺序观察同一断面： 1. 最早期：原生雕刻刀痕是否延伸到断口附近； 2. 初次断裂面：一组破碎、参差的断裂碴口； 3. 人工修磨痕（若有）：打磨、錾削把碴口削平，形成次级平整基面——卯孔打在这个面上；看到它即证明此处曾有一次有意识的修复作业； 4. 固定介质痕迹（若有）：铅锡、石灰、泥浆粘接残留； 5. 最晚期：二次破碎，把修平的基面、卯孔边缘再次崩碎——即今天肉眼常见的"孔缘破烂"状态。

判读口诀： - 有修平基面 + 规整卯 → 曾经规范修复；卯缘残破 = 修复后再次破坏，不能反推非修复孔； - 完全找不到修平基面、断裂碴直接连孔壁 → 非规范古修复孔，更可能是后世盗凿、现代取样孔。
